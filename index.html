End to end stock market pipeline

Market data collected with Python, landed in Azure Data Lake, modeled with dbt, and served from Snowflake and SQL Server into Power BI.

  2. 02 Land Azure Data Lake
  3. 03 Model dbt
  4. 04 Warehouse Snowflake, SQL Server
  5. 05 Report Power BI

GitHub Actions carries the pipeline from ingest through the report.

Collect

Python and Selenium pull stock and ETF data and land the files in Azure Data Lake.

Model

Power BI sits on the modeled tables so the numbers are readable without opening the warehouse.
